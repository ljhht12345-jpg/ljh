한신대학교 재학생

이준호

AI와 정보보안의 교차점을 목표로 공부하고 있습니다.

소개

한신대학교에 재학 중이며, 인공지능과 정보보안을 함께 다루는 분야로 진로를 잡고 있습니다. 학교 수업에서 배운 프로그래밍 기초를 직접 만든 프로젝트로 확장하는 방식으로 공부하고, 장기적인 로드맵을 세워 단계별로 실력을 쌓아가고 있습니다.

관심 분야

AI · 머신러닝

Python 기반의 PyTorch, scikit-learn을 활용한 모델 학습과 응용에 관심이 있습니다.

정보보안

네트워크 분석, 웹 취약점 진단, 리버스 엔지니어링을 중심으로 학습하고 있습니다.

프로젝트

테트리스 클론

Python(pygame)으로 먼저 구현한 뒤, C(ncurses)로 다시 작성했습니다. VS Code 환경에서 컴파일·실행 환경까지 직접 구성했습니다.

스네이크 게임

Python tkinter를 사용해 slither.io 스타일의 게임을 제작했습니다.

개발 환경 구축

Windows와 Ubuntu 듀얼부팅 환경을 직접 구성하고 AI 개발용 환경을 세팅했습니다.

기술 · 도구

Python C PyTorch scikit-learn Wireshark Burp Suite Ghidra Linux
